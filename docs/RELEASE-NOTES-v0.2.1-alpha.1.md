## 首次运行会发生什么

1. **SmartScreen 警告（"未知发布者"）** —— 这个包没有代码签名，属正常。点「更多信息」→「仍要运行」。
2. **一个询问是否优化启动速度的对话框** —— 说明为什么要添加 Windows 安全中心排除项。
   - 点「授权并添加」会弹出 **UAC 提权**，随后脚本把**安装目录**和 `%USERPROFILE%\.dsh` 加入排除列表；
   - 点「暂不添加」也能正常使用，只是每次冷启动更慢。
   - 这是明确的安全取舍：被排除的目录**不再被实时扫描**，请确认你信任其中的内容。
3. 之后是常规的登录与工作区引导。

## 自带内容

- 自定义图标：窗口/任务栏、托盘、关于面板、安装包与快捷方式
- 任务栏身份修复：固定到任务栏不再显示成 "Electron"
- **内置 `ds-harness-remote` 插件**：随包安装、默认启用，`role: both`，服务器指向 `https://sakakibara.ink:8443`
  - 首次连接需要**授权一次**（客户端角色需要设备授权；凭证不能预置，否则所有安装会共用同一个设备身份）
- 冷启动优化脚本：见上文对话框，之后也可手动运行安装目录下的 `defender-exclusions.ps1`

## 已知限制

- **没有自动更新**：新版本需要重新下载安装包
- **未签名**：SmartScreen 警告属正常
- 更新检查用的策略源站目前是占位地址，更新界面可能提示「暂时无法检查更新要求」——不影响使用
- 插件会把设备身份与连接指向 `https://sakakibara.ink:8443`
